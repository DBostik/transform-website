# Agent instructions

## Comments

Do not add code comments unless they explain a non-obvious *why* that the code itself cannot express.

Never leave comments about temporary workarounds. If a workaround is still in the code, fix it or name the constraint in the code; do not document it as a temporary comment.

When you touch code, delete stale comments in that code: comments that restate what the code already says, commented-out code, leftover TODO hacks, and notes that no longer match the implementation.
